# DREAD — Large slab floor replacements

Three matching top-down albedo textures: worn, damaged, moss/bones.
Replace the same filenames in the previous kit's textures folder.

Each complete square maps to2x2m. The new design uses approximately3 broad slabs
across and3 down, targeting50–90cm slabs, with quieter narrow grout and sparse
wear. Keep the texture repeat at2.0m; do not repeat the whole image per slab.

Colors and painterly style derive from the earlier floor. Generated with the
built-in image tool; exact prompts are included. Real-world dimensions are
mapping targets, not measurements guaranteed by image generation.

Check by hand: repeat seams in a3x3 tile preview, floor scale against the
256x192px diamond, palette/contrast under gameplay lighting. Seamlessness and
exact hex quantization are not certified. Native PNG sizes are in manifest.json.
